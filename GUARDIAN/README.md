# LION RISK GUARDIAN

Бот-охранник для cTrader. **Не торгует.** Следит за счётом и не даёт нарушить правила FTMO,
какой бы из твоих ботов ни открыл сделку.

## Зачем он нужен

При риске 0.25% на сделку челлендж проходится почти гарантированно, при 2% та же стратегия
превращается в монетку. Разница только в размере позиции. Охранник следит, чтобы размер
всегда был правильным, и чтобы правила FTMO нельзя было нарушить в принципе.

Плюс он сам пишет журнал всех сделок в CSV. Ручных выгрузок больше не нужно.

## Установка, 5 минут

1. cTrader → вкладка **Automate** → **New** → **cBot**.
2. Стереть всё, что там есть. Вставить содержимое `RiskGuardian.cs`.
3. Назвать `RiskGuardian`. Нажать **Build** (F6). Должно собраться без ошибок.
4. Открыть любой график, любой символ, любой таймфрейм. Добавить на него `RiskGuardian`.
   Он видит ВСЕ позиции счёта, а не только этот символ. Ставится один раз, не на каждый график.
5. В настройках бота проверить: **Режим = Monitor**. Запустить.

## Порядок включения. Не перепрыгивать

| Шаг | Что делать | Сколько |
|---|---|---|
| 1 | Демо-счёт, режим **Monitor**. Твои боты торгуют как обычно, охранник только пишет в лог, что сделал бы. | 1 неделя |
| 2 | Читаешь лог. Если он предлагает разумное — переключаешь на **Enforce** на демо. | 1 неделя |
| 3 | Смотришь журнал `guardian_trades.csv`. Считаем матожидание после издержек по каждому боту. | 1 вечер |
| 4 | Оставляешь одного бота с лучшим результатом. Покупаешь челлендж. Охранник в **Enforce**, риск 0.25%. | — |

**Никогда не ставить сразу в Enforce на реальный счёт.** Код проверен компилятором на заглушке
API, но не проверен на живом cTrader. Сначала демо.

## Что он делает

| Правило | Как работает |
|---|---|
| Риск на сделку | Считает риск по стопу и срезает лишний объём частичным закрытием |
| Позиция без стопа | Вешает аварийный стоп в 0.5 × ATR(14) дневного. Если не получилось — закрывает |
| Свой дневной лимит | По умолчанию 2% вместо пяти у FTMO. При достижении закрывает всё и запирает день |
| Свой общий лимит | По умолчанию 6% вместо десяти. При достижении закрывает всё и запирает счёт |
| Корреляция | Не пускает вторую позицию из группы в ту же сторону. EURUSD и GBPUSD во время данных США это одна ставка |
| Лимит позиций | По умолчанию 2 открытых, 1 на символ |
| Выходные | Уводит в ноль за час до закрытия пятницы |
| Новости | Уводит в ноль и блокирует вход в окне ±5 минут от события tier 3 |

## Главное правило, которое всё объясняет

**Риск на сделку × максимум сделок за день должен быть МЕНЬШЕ дневного лимита.**

При риске 1% и трёх сделках худший день это минус 3% против лимита 5%. Дневной лимит
физически непробиваем. При 2% достаточно двух с половиной убытков подряд.

На одношаговом челлендже лимит 3%, поэтому риск нужен вдвое меньше.

## Файлы

Охранник работает с папкой `Документы\LionGuardian\`:

- `guardian_trades.csv` — журнал сделок, создаётся сам. Это он нужен мне для расчёта матожидания.
- `news_events.csv` — файл новостей, создаёшь ты. Формат: `datetime_utc,currency,tier,title`.
  Если файла нет, блокировка по новостям просто выключена, бот об этом скажет в логе.

Пример `news_events.csv`:

```
datetime_utc,currency,tier,title
2026-09-12 12:30,USD,3,NFP
2026-09-16 18:00,USD,3,FOMC
```

## Настройки по умолчанию и почему такие

| Параметр | Значение | Откуда |
|---|---|---|
| Риск на сделку | 0.25% | В симуляции даёт 99.6% проход при реальном преимуществе |
| Свой дневной лимит | 2% | Своя стена стоит день, стена FTMO стоит счёт |
| Свой общий лимит | 6% | Буфер до десяти процентов FTMO |
| Максимум позиций | 2 | 0.25% × 2 = 0.5%, до дневного лимита далеко |
| Аварийный стоп | 0.5 × ATR(D1) | Срабатывает редко, нужен только чтобы риск не был бесконечным |

Пороги менять можно, но проверь главное правило выше после каждого изменения.
